# 澜知海洋 macOS 应用

先完成项目既有的本机环境准备，再从干净源码运行 `python3 desktop/build_app.py --output /a/new/output/directory`。双击“澜知海洋.app”打开独立窗口，使用系统 WebKit，无需另开终端或浏览器页。应用依赖本机源码工作区和 `.venv`，不是可移机的完整发行包。

使用既有 `tools/start_app.py` 和默认 8871 端口，保留 `~/Library/Application Support/MarineFisheries/workspace` 下的记录与密钥。启动前确认进程与监听归属；关窗保留已启动的项目后台，避免中断采集或同步。停止后台仍使用原启动器的 `--stop`，不会结束其他服务。

五个业务分区移到固定侧栏，移动端变为紧凑导航。认证、离线待同步队列、原请求重试和工单权限保持原流程。不会自动连接现场设备、下载模型或执行预测。

原生检查使用 19013 端口、独立临时目录和非持久 WebKit，不接触正式记录。构建包不含数据库、密钥、模型或业务资料，仅本机临时签名，未作公证发行。
