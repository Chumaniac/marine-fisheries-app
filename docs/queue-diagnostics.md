# 本机同步队列诊断

日期：2026-10-18。范围：本地队列源码与合成验证；不包含现场、生产或模型效果验收。

连接有效会话，展开“待同步操作与冲突处理”，点击“导出同步诊断”可下载 `marine-queue-diagnostics.json`。读取当前 IndexedDB 快照后再次核对账户，期间切换或租期失效则停止导出。导出使用只读事务，不删除、发送、重试或重建原请求。

## 内容与证据

- `schema` 为 `marine.queue-diagnostics/v1`，证据类型明确为本机诊断快照，不是服务端送达证明。
- 计数覆盖当前租户、主体和作用域中的全部已读取记录；明细按原队列顺序最多 32 条，省略数量单独给出。
- 每项仅有序号、固定操作名称、同步状态、合法尝试次数和固定失败类别。次数异常时为 `null`，不会编造零次。
- 只识别重试预算耗尽、窗口过期、身份、冲突、可重试响应、请求拒绝和服务端错误等固定类别。未知值标为 `not-recorded`，不表示从未发生错误。
- 请求/批次/证据编号、站点、租户、人员、scope hash、业务正文、附件及文件名、原始错误和凭据均不进入文件。

会话检查同时用于队列选择、接纳、恢复及手动处置，拒绝缺失身份字段、非有限租期与已过期身份；不把未绑定的旧记录归给当前账户。原记录仍保留，无法识别的历史状态应先核查，不能依据诊断文件自动重发。重试次数或排序/依赖元数据异常时转为人工处理，不发送请求，保留原请求编号、原始次数和失败信息，避免未知计数绕过重试预算。

## 容量与生命周期

读取最多 1001 条以检测 1000 条输入上限；超过上限或当前作用域记录无法解析时停止，不发布部分诊断作为完整结果。明细最多 32 条，格式化 UTF-8 JSON 最多 16 KiB。下载 URL 在下载启动后及离页时释放。原有每账户队列、文件、重试次数与窗口边界保持。

静态外壳缓存更新为 v10，应用包按现有锁定依赖重建；IndexedDB 版本和业务记录没有迁移或清理。输出大小与保留数量有用例，真实 CPU、RSS 与现场吞吐未测量。

## 验证与来源

21 项 Node 网络/队列/工作流测试、55 项 Python 测试及事件契约的 4 个正例和 9 个反例通过。Python 输出包含 219 条已有依赖弃用告警，未为此升级依赖。真实独立 Chrome 连接临时回环合成服务，验证实际诊断下载、另一租户记录排除、敏感字段未出现，并回放原有分页、人工重试与手机布局。专用服务已停止。
