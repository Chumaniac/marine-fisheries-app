## 2026-11-06 有界上下游谱系

仅下游；下游遍历不反向扩展共同投入批次。缺失/不可见引用只记未解析数量，不返回其编号。
不读取证据正文/历史操作者，不调用账本，也不触发召回或其他业务写入。

一次读取限制100批次、200条返回关系、1–12层（默认8）、1000次/行元数据检查及64KiB单条
载荷；有界扫描另有一行探测。纯上游使用同租户主键查询；下游/双向扫描有界前缀，超限
明确为部分结果。节点/关系/深度/元数据/缺失引用和循环均保留原因，不能把空的已显示
下游当作“没有其他影响”。同进程最多两个检查，拒绝积压；数据来自同一只读SQL快照。

独立谱系起点可继续只读展开节点，不改变操作批次或未提交队列。修改查询、退出账号和

合规验收。未同步操作不在此范围。面向更大数据量需另建受控索引/分页方案，本轮未迁移
