# 澜知海洋 使用说明

## 主流程

建采集任务 → 填写/导入记录 → 质量核对 → 分类与分析 → 教师/业务复核 → 导出

1. 启动后打开终端给出的本机地址。先用合成示例建立采集记录，再录入自己的获授权资料。
2. 核对缺失字段、单位与质量提示。努力量缺失的记录不能解释成可靠 CPUE；图像分类也不能替代真实捕捞数量/重量。
3. 模型识别需要匹配的 ONNX 与校准 report.json；缺少时使用手动录入/核对流程。完成复核后导出记录和依据。

## 操作原则

先用合成示例验证，再导入自己的获授权资料。必填项旁的提示说明预期格式；处理时等待明确的完成/失败状态，不连续重复提交。保存后先重新打开记录核对，再导出。空状态不会伪造历史数据；错误不自动转为成功结果。

## 目录与恢复

macOS：~/Library/Application Support/MarineFisheries/workspace；其他系统：~/.local/share/marine-fisheries/workspace。数据库、签名密钥、模型与运行记录不进入 Git。

迁移电脑时先正常退出应用，确认没有在途任务，备份整个私人数据目录；安装同版程序后恢复到相同位置。不要只复制数据库主文件而漏掉 WAL、附件或规则。版本不兼容时先备份，再按显式升级检查处理，不删除数据库以“修好”程序。

## 移动端与键盘

网页提供窄屏布局与可滚动表格。桌面包运行在当前电脑，本机回环地址不能直接在另一部手机打开；这不是已部署的手机云服务。用 Tab 在控件间移动，焦点可见；降低动态效果的系统偏好会被保留。

## 能力条件

发布包不含原始鱼类图片、训练集、预训练/微调权重、生产身份配置或 Fabric 私钥。Kafka/Flink/IPFS/Fabric/OIDC 需要独立部署与验收；本地台账不是区块链上链。模型精度、真实渔场效果和生产吞吐量未由源码安装证明。

## 关闭窗口与停止后台

关闭桌面窗口会保留已启动的评分/采集后台，避免中断在途任务。再次打开同一安装位置时，会验证原进程、脚本与端口归属后重新连接，不启动第二套服务。

需要完全停止或移动/更新程序时，先确认没有在途任务，再用安装包中启动器的 --stop。若程序位于 ~/Applications：

```sh
marine_runtime="$HOME/Applications/澜知海洋.app/Contents/Resources/runtime"
"$marine_runtime/python/bin/python3" "$marine_runtime/app/tools/start_app.py" --stop
```

归属不符时启动器会拒绝停止，不会结束未知服务。数据库、原稿、规则和报告均保留。
