# 观测与批次复核

按站点和批次查看观测、来源和质量问题。网络状态会影响哪些步骤可以继续，导出时保留当前范围和来源。

## 工作台

新增合成站点/设备/水质表单填入、当前页来源表格、组合筛选后的JSON/CSV导出。修复切换站点后可能将旧数据标记成新站点导出的缺陷。

## 数据、异常与资源边界

导出绑定实际已载入的站点与scopeHash，切换后需刷新；字段白名单排除原始payload与凭据，CSV公式前缀转义。仅当前已载入来源页，不声称完整数据集或预测/渔获全量导出。

## 历次验证

119项web检查、构建、隔离合成API登录后2条来源导出/环境筛选1条、切站点拒绝旧范围导出、桌面/390px/320px。红/绿证据保留于任务evidence。

## 本地启动

```sh
pnpm --dir web install --frozen-lockfile && pnpm --dir web run build
# 使用README已有本地API启动流程；仍需登录本地会话。
```


实际本机验收修复：工单来源从服务器持久化JSON回读后，以固定不可变字段比较元数据，不再将字段排列顺序误判成来源变化。重复关联与渔获提交继续检查来源版本、设备、类型、站点和时间；新增回归证明相同内容可继续，真实字段变化仍拒绝。

实际队列隔离修复：有明确服务器工单绑定的环境/渔获操作按工单排序，已拒绝的另一工单不会阻断独立工单。保留原请求、幂等键、失败证据和重试计数；同工单、显式共享批次依赖及缺少完整绑定的旧记录继续保持顺序与拒绝边界。
