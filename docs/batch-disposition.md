# 当前批次处置摘要

选择批次并查询溯源后，可在“批次处置摘要”中依次查看当前账户未确认操作、冷链异常、待确认存证、证据和后续页。每项使用原生链接定位既有控件，只定位和阅读，不触发重试、处置提交、原件生成或自动确认。

摘要复用已有溯源响应、逐次链上核对结果和内存队列；没有新增接口请求或轮询。汇总使用服务端整个批次的计数，逐条记录仍按每页100条翻页。登记数量、本机同步、链上核对和原件完整性分别呈现；即使记录状态为“已送达”，也不会据此宣布全部证据已通过。

会话、批次、过滤范围、版本或联网状态改变时，旧快照失效并提示重新查询。失效会话隐藏摘要；未知、格式不完整及超过队列范围的输入不会显示完成结论。只检查当前账户元数据，不读取请求正文、附件或原始错误。输入最多1000条、当前账户最多100条；动作列表固定最多7项。显示内容没有变化时保留原DOM，防止轮询打断键盘焦点。业务IndexedDB保留，静态壳缓存更新为v12。

方法参考：[Paperclip有界只读任务历史](https://github.com/paperclipai/paperclip/blob/9179d8dcc3e908c217fde4f63c9d08ccf8132eeb/packages/paperclip-runner/src/protocol-actions/get-task-history.ts)（MIT）与[OpenShell分类、证据和处理建议](https://github.com/NVIDIA/OpenShell/blob/0bfa1e8b0261ca34aee134dda2829aa15f2a7b90/crates/openshell-prover/src/report.rs)（Apache-2.0）；固定2026-10-19热榜审查版本，未引入上游服务或改变运行权限。

本轮验证区分纯状态规则、合成回环API/浏览器、已安装模型与原始证据复用。摘要功能不构成现场预测效果、真实业务或生产验收。
