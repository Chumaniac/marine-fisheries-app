# 浅色工作台改版 · 2026-10-12

已将海洋渔业系统调整为 Genkoy 的浅色视觉体系，保持四个模块、原有页面顺序与操作流程。原128个元素标识、15个表单及12个二级分区均保留，没有改动后端接口、模型、数据库或验收批次。

## 设计与实现

- 浅灰主背景 `#F8F9FA`、白色卡片、`#E4E4E7`分隔、`#18181B`正文与`#62626B`辅助文字；黑色主按钮，白底次按钮，危险操作单独用语义色。
- 保留桌面原两栏布局；统一卡片、表单、按钮、间距、12px基础圆角和轻阴影。交接、加工、环境和渔获表单各自成组，原内容顺序不变。
- 字体复用Genkoy本机安装的Inter Latin variable，字体文件约47.1KiB，随页面本地提供并缓存，SIL OFL许可证随仓库保留；中文沿用系统字体，不请求外部字体服务。
- 图表使用中性灰阶，热力格显示实际数值，新增热力与地理数据的表格视图。原折线数据表、筛选和预测过期提示保留；图表关闭动画。
- 所有按钮高度至少44px，移动端输入文字16px；可见键盘焦点、跳转主内容链接、原生表单标签与状态播报、表单内错误提示、忙碌状态和动效减弱规则均已补齐。切换身份时清空表单反馈。
- 主题变量集中于 `web/style.css`，沿用当前原生HTML/JavaScript和已有ECharts。没有额外组件框架或动画依赖。资源版本与Service Worker缓存清单同步，修复了实际观察到的新页面混用旧样式问题。

## 验证

- **42项Python、12项JavaScript通过**，Ruff、前端构建、语法与改动格式检查通过；依赖已有219条弃用警告保留。
- **实际浏览器**：复用既有公开图片识别为绿青鳕；151条成熟样本、历史预测与模型来源可读；原850克已送达批次及两份证据仍完整，双副本和账本核验通过，待链操作0，服务ready为true。非法回退状态在提交前被阻止，表单旁显示错误，没有新建业务批次或重生成预测。
- **四种屏宽**：1280、768、390、320 CSS像素下均无页面横向溢出，表单无缺失标签，所有可见按钮高度至少44px。键盘跳转主内容及Tab顺序实测通过，焦点轮廓为2px实线。
- **实际服务中断**：短暂停止本项目API/网关后，刷新仍显示浅色页面和已有站点快照，明确标记缓存；未写入新业务操作。服务已经恢复。此项验证不等于海上弱网或网络时延基准。
- **对比度**：正文16.81:1、辅助文字5.49:1、主按钮18.88:1、输入框边界4.83:1、错误文字5.91:1。上述组合达到相应WCAG AA对比度阈值；不据此宣称整个产品已获无障碍认证。

未进行真实读屏软件验收、200%字体缩放专测或同条件改版前后性能基准；没有把界面改版当作现场效果或生产上线。图表表格最多使用当前图表的有界数据，字体本地缓存，不增加后台轮询和生成请求。
